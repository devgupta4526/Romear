# Design reference boards

These are ROMEAR concept boards in warm cream/forest green/terracotta. Use them as **visual references only**. They are NOT production Android layouts, not individual validated screens, and not a guarantee of factual local content. Some boards contain illustrative placeholder numbers, fictional places and generated text. The XML components, content and permissions must follow the specs and actual data. Do not embed whole screenshots as a UI.
